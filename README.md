# TaskBoard 🚀

Учебный проект по Go. Сервис для управления задачами (TODO) с HTTP API и CLI-клиентом.

## 📚 С чего начать (Ритмика проекта)

Не пытайся написать всё сразу! Иди строго по шагам. После каждого шага у тебя должен быть работающий код и зеленые тесты.

### Шаг 1: Модель (`internal/task`)
*   **Задача:** Открой `task.go`. Заполни структуру `Task` и напиши метод `Validate()`.
*   **Проверка:** Открой `task_test.go` (там уже есть заготовка), запусти `go test ./internal/task/...`. Тесты должны пройти.

### Шаг 2: Хранилище (`internal/storage`)
*   **Задача:** Открой `memory.go`. Это просто мапа с мьютексом. Реализуй методы `Create`, `Get`, `List`, `Update`, `Delete`. Не забудь про `sync.RWMutex`.
*   **Проверка:** Запусти `go test ./internal/storage/...`.

### Шаг 3: Бизнес-логика (`internal/service`)
*   **Задача:** Открой `service.go`. Здесь мы связываем модель и хранилище. Реализуй методы `Add`, `List` (с фильтрацией), `MarkDone`.
*   **Проверка:** Запусти `go test ./internal/service/...`.

### Шаг 4: HTTP API (`internal/httpapi`)
*   **Задача:** Открой `handlers.go` (если файл называется `habdlers.go` — переименуй!). Напиши хендлеры для приема JSON и отправки ответов.
*   **Проверка:** Запусти `go test ./internal/httpapi/...`.

### Шаг 5: Точка входа и сохранение (`cmd/server`)
*   **Задача:** В `cmd/server/server_main.go` собери всё вместе: создай хранилище, сервис, роутер и запусти сервер.
*   **Проверка:** Запусти `go run ./cmd/server` и попробуй сделать запрос через терминал:
  `curl -X POST localhost:8080/tasks -d '{"title":"learn go"}'`

### Бонус (когда всё заработает)
*   Допиши `internal/storage/presist.go`, чтобы данные сохранялись в `tasks.json`.
*   Допиши `cmd/cli/cli_main.go`, чтобы управлять задачами из терминала.
